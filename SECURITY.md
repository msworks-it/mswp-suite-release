# Security policy

This policy covers every plugin of the MSWorks WordPress Suite (`mswp-*`).

## Supported versions

Security fixes are released for the latest version of each plugin. Please update before reporting.

## Reporting a vulnerability

Please do not open a public issue. Write to **antonio.murabito@msworks.it** with:

- the plugin and version;
- the steps to reproduce, and what an attacker can achieve;
- whether the issue is already public or being exploited.

You will get an acknowledgement within 3 working days. Once the issue is confirmed, the fix is
released as soon as possible and the reporter is credited in the changelog, unless they prefer
otherwise. Please give us a reasonable time to ship the fix before disclosing it.
